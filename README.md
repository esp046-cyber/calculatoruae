# AED ⇄ PHP Calculator (PWA)
Static, no build step. Live: https://esp046-cyber.github.io/calculatoruae/

- Running-total calculator with live AED ⇄ PHP conversion (open.er-api.com)
- Tap the rate line to set a custom rate and a flat AED fee (uses the in-app keypad)
- Tap the green total to copy it; History keeps the last 10 calculations
- Works offline with the last known rate. After editing any file, bump the cache name in `sw.js`.
